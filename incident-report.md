# 🚨 SOC Incident Response Playbook (Splunk)

## 📌 Overview

This project simulates a real-world **SOC incident response workflow** using Splunk.

It demonstrates how a SOC analyst:

* Detects a brute-force attack
* Investigates suspicious activity
* Responds to alerts
